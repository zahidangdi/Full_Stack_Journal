## 💡 Key Concepts & Quick Notes

### Async vs Sync
- **Async**: Parallel, non-blocking execution using callbacks, promises, and `async/await`.
- **Sync**: Sequential, step-by-step blocking execution.

### What are Modules?
Modules are isolated, reusable blocks of code wrapped in individual JavaScript files, exported with `module.exports` and loaded with `require()`.
